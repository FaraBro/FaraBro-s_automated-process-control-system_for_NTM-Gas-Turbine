The language of this project is currently only Russian.

Это - АСУ ТП для управления газовыми турбинами комбинированного цикла из мода игры Minecraft - Nuclear Tech Mod (1.7.10).
Для его работы также требуется мод OpenComputers. Код написан на ЯП Lua, исходный код можно увидеть выше.

## Установка

Для установки этого АСУ ТП в ваш мир сделайте след. шаги:

1. Установите файл turbine.lua
2. Откройте файл turbine.lua с помощью любого редактора и укажите настройки.
3. Сохраните изменённый файл
4. Установите на сервер OpenComputers OpenOS
5. Переместите полученный файл в директорию home сервера
6. Подключите сервер к турбинам комб. цикла проводами из OpenComputers
7. Если вы отключили автоматическое обноружение турбин вручную укажите адресы турбин в файле turbine.lua
8. Запустите сервер и напишите в терминале имя файла (с расширением)


Дополнительно:

- Можно сделать так, что бы скрипт запускался автоматически при запуске OS, для этого напишите имя скрипта в файле .shrc (этот файл находится в директории home)


### Частые ошибки

- Если OpenComputers не видит скрипт, но при этом он находится в директории home жёского диска на котором OS перезапустите мир


## Известные проблемы

- При относительно большом количестве управляемых турбин комб. цикла и при выводе информации в терминал экран мигает (низкая скрость обновления экранов в OpenComputers)


## Настройки

Настройки находятся в файле turbine.lua.

- outputInfo_To_Console - Определяет вывод в терминал информации об турбинах, при включении требуется подключённый монитор, GPU или CPU с встроенной видеокартой, больше мощностей сервера и энергии от источника энергии. Значение true - вкл, false - выкл. По умолчанию выкл.

- AutoSearchTurbines - Автоматический поиск турбин, при отключении требуется вручную вводить адресы турбин комб. цикла. Значение true - вкл, false - выкл. По умолчанию вкл.
 
- mode - режим работы. Режимы:
	- 1 - режим работы сгорания, всё топливо сгорает если есть. Кол-во излишек или недостатка энергии не учитывается. Если есть топливо турбина начинает горение и выводится на макисмальную мощность.
	- 2 - режим работы как аварийного генератора электроэнергии. Турбина начинает горение при недостатке электроэнергии. Турбина включается при 75% заполнености аккумулятора, выключается при 95%. График мощности: https://www.desmos.com/calculator/bfptuvzvig
		- Требует указания параметра AutoSearchEnergyStorages - автоматический поиск хранилища электроэнергии. Учтите, если включенно будет мониторится все аккумуляторыные системы подключённые к серверу. Значение true - вкл, false - выкл. По умолчанию вкл.
		- Требует подключения схемы: энергосеть -> аккумулятор(-ы) -> энергосеть и линию передачи информации: аккумулятор(-ы) -> сервер.
