The language of this project is currently only Russian.

Это - АСУ ТП для управления газовыми турбинами комбинированного цикла из мода игры Minecraft - Nuclear Tech Mod (1.7.10).
Для его работы также требуется мод OpenComputers. Код написан на ЯП Lua, исходный код можно увидеть выше.

## Установка

Для установки этого АСУ ТП в ваш мир сделайте след. шаги:
1. Установите файл <a href="turbine.lua" download="turbine.lua">turbine.lua</a>
2. Откройте файл turbine.lua с помощью любого редактора и укажите настройки.
3. Сохраните изменённый файл
4. Установите на сервер OpenComputers OpenOS
5. Переместите полученный файл в директорию home сервера
6. Подключите сервер к турбинам комб. цикла проводами из OpenComputers
	- Если вы отключили автоматическое обноружение турбин вручную укажите адресы турбин в файле turbine.lua
7. Запустите сервер и напишите путь к файлу (с расширением)
	- Также по желанию напишите это в .shrc (это автозапуск)
	- Если OpenComputers не видит скрипт, но при этом он находится по пути, который вы указали, то перезапустите мир Minecraft.

## Настройки

Настройки находятся в начале файла turbine.lua.
Форматы значений:
- boolean: true (включено) или false (выключено).
- integer: целое число.

- outputInfo_To_Console - Определяет вывод в терминал информации об турбинах, при включении требуется подключённый монитор, GPU или CPU с встроенной видеокартой, больше мощностей сервера и энергии от источника энергии.
	- Значение boolean. По умолчанию false
- AutoSearchTurbines - Автоматический поиск турбин, при отключении требуется вручную вводить адресы турбин комб. цикла.
	- Значение boolean. По умолчанию true
 
- mode - режим работы.
	- Значение integer. По умолчанию 1
	- Режимы:
		1. режим работы сгорания (1), всё топливо сгорает если есть. Кол-во излишек или недостатка энергии не учитывается. Если есть топливо турбина начинает горение и выводится на макисмальную мощность.
		2. режим работы как аварийного генератора электроэнергии (2). Турбина начинает горение при недостатке электроэнергии. Турбина включается при 75% заполнености аккумулятора; выключается при 95%; мощность регулируется согласно [графику](https://www.desmos.com/calculator/bfptuvzvig)
			- Требует указания параметра AutoSearchEnergyStorages - автоматический поиск хранилища электроэнергии. Учтите, если включено будет мониторится все аккумуляторыные системы подключённые к серверу. Значение true - вкл, false - выкл. По умолчанию вкл.
			- Требует подключения схемы: энергосеть -> аккумулятор(-ы) -> энергосеть и линию передачи информации: аккумулятор(-ы) -> сервер.
