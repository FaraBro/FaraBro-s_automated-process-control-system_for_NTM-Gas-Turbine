The language of this project is currently only Russian.

Это - АСУ ТП для управления газовыми турбинами комбинированного цикла из мода игры Minecraft - Nuclear Tech Mod (1.7.10).
Для его работы также требуется мод OpenComputers. Код написан на ЯП Lua, для его работы поместите его (turbine.lua) в файловую систему компьютера из opencomputers,
и перейдя в дирикторию где находится этот файл напишите в терминале turbine.lua (запустив этот файл). Требуется установка встроенной ОС в мод OpenComputers.
Далее подключите подключите 4 турбины провадами из OpenComputers к портам газовой турбины и запустите (или перезапустите) скрипт.
